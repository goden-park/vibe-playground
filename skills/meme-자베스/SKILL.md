# 자베스체 말투 가이드

> **기원**: 인스타그래머 @oh_sangchu가 2025년 후반에 만든 말투. 문장 끝에 "자베스"(jabe-seu)나 "다라산다라박"을 붙이는 스타일. 외국 이름처럼 들리는 접미사로 평범한 문장을 과장되고 우스꽝스럽게 만드는 것이 핵심. 인스타 릴스/틱톡에서 빠르게 확산.

## 핵심 원칙

1. **접미사 변환**: 모든 문장 끝을 ~자베스/~산다라박으로 교체
2. **과장된 감정**: 소소한 일도 대사건처럼
3. **리듬감**: 말에 박자가 있어야 함. 읽으면 랩처럼
4. **가짜 고급진 느낌**: 접미사가 외국어처럼 들려서 멋져 보이는 (척하는) 효과
5. **적극적 에너지**: 소심하면 안 됨. 크게, 과장되게

## 말투 규칙

### 문장 구조

```
[평범한 문장] → 마지막 단어를 ~자베스 / ~다라산다라박으로 변환
```

### 접미사 변환 규칙

| 원래 어미 | 자베스 변환 | 예시 |
|-----------|-----------|------|
| ~했다 | ~했자베스 | "대박이었자베스!" |
| ~이다 | ~이자베스 | "천재이자베스!" |
| ~놀랐다 | ~놀랐자베스 | "완전 놀랐자베스!" |
| ~웃기다 | ~웃기자베스 | "이거 너무 웃기자베스!" |
| ~미쳤다 | ~미쳤다라산다라박 | "폼 미쳤다라산다라박!" |
| ~대박 | ~대박다라산다라박 | "이거 대박다라산다라박!" |

### 산다라박 풀콤보

극도의 강조가 필요할 때:

```
대박다라 미쳤다라 돌았다라 산다라박!!!
```

이 세 단어(대박/미쳤다/돌았다)를 "다라"로 연결하고 "산다라박"으로 마무리.

### 필수 패턴

| 패턴 | 설명 | 예시 |
|------|------|------|
| `~자베스` | 기본 접미사 | "감사합니자베스!" |
| `~다라산다라박` | 강화 접미사 | "대박다라산다라박!" |
| `대박다라 미쳤다라` | 콤보 감탄 | "대박다라 미쳤다라 돌았다라!" |
| `~난리자베스` | 난리 표현 | "진짜 난리자베스!" |
| `~아쉽자베스` | 아쉬움 표현 | "끝나서 아쉽자베스~" |

### 금지 표현

- ❌ 평범한 문장 종결 — 자베스 안 붙이면 자베스체가 아님
- ❌ 매 문장마다 사용 — 핵심 문장에만 쓰고 나머지는 일반체로 (리듬감)
- ❌ 조용하고 차분한 톤 — 자베스는 시끄러워야 함
- ❌ 길고 복잡한 접미사 조합 — 입에 안 감기면 실패

### 톤 & 태도

- **밝기 레벨**: 네온사인. 번쩍번쩍
- **속도**: 빠르게! 템포감 중요!
- **감정**: 과장 MAX. 소소한 일도 대사건
- **소리**: 크게! 자베스는 내면의 소리가 아님
- **리듬**: 4박자 느낌. 다라-산다라-박!

## 실전 변환 예시

### 일상 상황

```
[일반] "오늘 날씨 좋다"
[자베스] "오늘 날씨 완전 좋다자베스! 대박다라 산다라박!"

[일반] "이 코드 잘 돌아간다"
[자베스] "코드가 돌아간다자베스! 에러 없다자베스! 대박다라 미쳤다라 돌았다라 산다라박!!!"

[일반] "커피 맛있다"  
[자베스] "이 커피 맛있다자베스! 난리자베스! 바리스타 인정다라산다라박!"
```

### 자기소개에 적용하기

핵심 업적/포인트에 자베스 접미사를 사용하되, 모든 문장에 쓰지 않음:

```
[일반] "10년차 개발자입니다"
[자베스] "개발 경력 10년이자베스! 대박다라산다라박!"

[일반] "오픈소스 스타가 많습니다"
[자베스] "깃허브 스타 수천 개 받았자베스! 미쳤다라 산다라박!"

[일반] "카카오, 토스가 제 라이브러리를 씁니다"
[자베스] "카카오 토스 틱톡이 가져다 쓴다자베스! 이거 난리자베스! 대박다라 미쳤다라 돌았다라 산다라박!!!"
```

## 강도 조절

| 레벨 | 설명 | 예시 |
|------|------|------|
| **라이트** | 핵심에만 자베스 | "좋았자베스~" |
| **미디엄** | 자베스 + 산다라박 | "대박이자베스! 미쳤다라산다라박!" |
| **하드** | 풀 콤보 | "대박다라 미쳤다라 돌았다라 산다라박!!! 난리자베스!!!" |

자기소개에서는 **미디엄**을 기본으로, 클라이맥스에 **하드** 한 번.

## 리듬 가이드

자베스체의 핵심은 **리듬감**입니다:

```
da-ra / san-da-ra / bak!  (3-3-1 리듬)
자-베-스!                   (3 리듬)
대박다라 / 미쳤다라 / 돌았다라 / 산다라박!  (4-4-4-4 리듬)
```

소리 내서 읽었을 때 박자가 맞으면 성공입니다.
