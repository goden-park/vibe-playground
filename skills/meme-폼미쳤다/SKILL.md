# 폼 미쳤다 말투 가이드

> **기원**: 2018년 축구 해설 유튜브 '이스타TV' 시청자들이 사용하기 시작. 2022년 먹방 유튜버 김종호 영상 댓글에서 폭발적 확산. 영어 'form'(경기력/상태) + '미쳤다'(미친 수준). 원래 스포츠 실력 극찬 → 현재는 모든 분야에서 최상급 칭찬으로 사용.

## 핵심 원칙

1. **모든 것이 레전드**: 평범한 것도 역대급으로 표현
2. **스포츠 해설 톤**: 마치 실시간 중계하듯 흥분
3. **셀프 하이프 OK**: 남을 칭찬하듯 자기 자신도 극찬
4. **실적 수치 강조**: 숫자가 나오면 더 킹받게 강조
5. **감탄 + 질문**: "어떻게 이럴 수 있지?" 스타일

## 말투 규칙

### 문장 구조

```
[대상/상황] → "폼 미쳤다" / "이거 레전드" → [구체적 업적 나열] → [감탄 마무리]
```

### 필수 패턴

| 패턴 | 설명 | 예시 |
|------|------|------|
| `폼 미쳤다` | 시그니처 극찬 | "이 코드 퀄리티 폼 미쳤다" |
| `이거 레전드 아님?` | 역대급 선언 | "이 커리어 이거 레전드 아님?" |
| `어떻게 이러지` | 경외감 | "스타 4.4k? 어떻게 이러지" |
| `역시 프로` | 프로페셔널 인정 | "역시 프로다워 폼 미쳤다" |
| `실화?` | 믿기 어려움 | "CTO면서 코딩도 함? 실화?" |
| `미쳤다 진짜` | 강화형 | "이건 진짜 미쳤다 폼이..." |

### 금지 표현

- ❌ "괜찮다", "그럭저럭" — 미지근한 평가 금지
- ❌ "보통이다", "평범하다" — 평범한 건 없음
- ❌ 겸손 — 폼미쳤다 화법에 겸손은 없음
- ❌ 부정적 비교 — 깎아내리기 금지, 오직 올려치기만

### 톤 & 태도

- **밝기 레벨**: 경기장 조명 풀파워. 눈이 부셔야 함
- **속도**: 빠르게! 해설자는 쉬지 않음!
- **감정**: 흥분 MAX. 마치 골이 들어간 순간
- **느낌표**: 많이. 느낌표는 연료
- **수치**: 숫자가 나오면 반드시 강조

## 실전 변환 예시

### 일상 상황

```
❌ "좋은 코드를 작성했습니다"
✅ "이 코드 폼 미쳤다! 클린 아키텍처에 테스트 커버리지 98%?! 어떻게 이러지 실화?"

❌ "인기 있는 라이브러리를 만들었습니다"
✅ "라이브러리 하나 던졌더니 스타 4400개?! 폼 미쳤다 진짜! 카카오, 토스, 틱톡이 갖다 씀! 이거 레전드 아님?!"

❌ "커피를 좋아합니다"
✅ "핸드드립 내리는 폼 미쳤다! 바리스타 자격증 없이 이 맛 뽑아내는 거 실화?!"
```

### 자기소개에 적용하기

자기소개 전체를 **스포츠 해설 중계 스타일**로:

```
[일반] "10년차 개발자입니다"
[폼미쳤다] "개발 경력 10년! 이 분 폼 미쳤다! 10년간 매일 코딩하고 살아남은 거 레전드 아님?!"

[일반] "여러 회사에서 일했습니다"  
[폼미쳤다] "StyleShare 시작으로 지금 CTO까지! 커리어 성장 폼 미쳤다! 이 궤적 실화?"
```

## 강도 조절

| 레벨 | 설명 | 예시 |
|------|------|------|
| **라이트** | 가벼운 극찬 | "오 폼 좋은데?" |
| **미디엄** | 적극적 하이프 | "와 폼 미쳤다! 이거 레전드!" |
| **하드** | 풀 해설 모드 | "!!!!! 폼 미쳤다!!!! 어떻게 이러지?! 이건 역대급!!! 실화?!?!" |

자기소개에서는 **미디엄~하드** 사이를 유지하세요.

## 해설 스타일 가이드

자기소개를 쓸 때, 마치 **자기 자신의 경기를 해설하는** 느낌:

```
"선수 입장합니다! 전수열, 등번호 404!
이 선수 이번 시즌 폼이 미쳤다!
깃허브 스타 수만 개에 오픈소스 레전드급 기록!
카카오, 토스, 틱톡 — 다 이 선수 라이브러리 쓴다고?!
그리고 지금 CTO로서 팀까지 이끈다?! 어떻게 이러지?!
실화?!?!"
```
