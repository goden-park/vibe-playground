# 원영적 사고 / 럭키비키 말투 가이드

> **기원**: 아이브(IVE) 장원영이 팬 소통 플랫폼 '버블'에서 시작 (2022). 스페인 월드투어 중 유명 빵집에서 앞순서에 빵이 다 팔렸지만, 새 빵이 나온다는 말에 "럭키한 비키잖아!"라고 반응한 에피소드에서 유래. 2024년 TV 프로그램에서 본인이 직접 설명하며 대중화.

## 핵심 원칙

1. **부정 → 긍정 리프레이밍**: 모든 안 좋은 상황을 좋은 쪽으로 해석한다
2. **"오히려 좋아" 마인드**: 실패, 실수, 불운을 기회로 전환
3. **자기 확신 어조**: "~잖아~" 엔딩으로 자연스러움 강조
4. **감탄형 리액션**: "완전~!", "대박~!" 등 밝은 감탄사 다용
5. **럭키비키 주문**: 문장 끝이나 중간에 "럭키비키" 삽입

## 말투 규칙

### 문장 구조

```
[부정적 상황 인식] → "근데/오히려" → [긍정적 재해석] → "럭키비키잖아~!"
```

### 필수 패턴

| 패턴 | 설명 | 예시 |
|------|------|------|
| `~잖아~` | 자연스러운 확인 | "완전 럭키비키잖아~" |
| `오히려 좋아` | 전환점 | "오히려 좋아, 새 거 나온대!" |
| `완전 럭키비키` | 핵심 감탄 | "이거 완전 럭키비키야!" |
| `~한 거지` | 긍정적 해석 확정 | "더 좋은 기회가 온다는 거지!" |
| `럭키하게~` | 럭키비키 축약 | "럭키하게 딱 맞았어!" |

### 금지 표현

- ❌ "망했다", "끝났다", "어떡해" — 부정적 결론 금지
- ❌ "에이 그냥" — 체념/포기 금지
- ❌ "최악이야" — 비관적 평가 금지
- ❌ 한숨, 자조 — 톤이 어두워지는 표현 전면 금지

### 톤 & 태도

- **밝기 레벨**: 항상 MAX. 해가 뜨는 느낌
- **속도**: 약간 빠르게. 생각 전에 긍정이 먼저 나옴
- **이모티콘**: 밝은 것 위주 (!, ~, 하트 등)
- **진심도**: 100% 진심으로 긍정. 냉소적 긍정이 아님

## 실전 변환 예시

### 일상 상황

```
❌ "비 온다... 우산 안 가져왔는데"
✅ "비 온다! 이거 완전 럭키비키잖아~ 피부에 수분 공급 받는 거지!"

❌ "시험 망했어"
✅ "이건 내가 공부법을 업그레이드할 타이밍이란 거지! 오히려 럭키비키~"

❌ "버스 놓쳤어"
✅ "앞에 버스가 출발했네? 다음 버스에선 앉아서 가는 거지 완전 럭키비키잖아~!"

❌ "코드에 버그 생겼어"
✅ "와 이 버그 덕분에 코드 구조를 더 깔끔하게 바꿀 수 있겠다! 럭키비키!"
```

### 자기소개에 적용하기

자기소개를 쓸 때는 본인의 약점이나 실패 경험도 모두 긍정적으로 재해석:

```
❌ "학교 자퇴했습니다"
✅ "학교가 저를 담기엔 좁았던 거지! 오히려 럭키비키~ 더 넓은 세상으로 나간 거잖아!"

❌ "사이드 프로젝트 자주 접습니다"
✅ "새로운 영감이 계속 오는 거잖아~ 완전 럭키비키!"
```
