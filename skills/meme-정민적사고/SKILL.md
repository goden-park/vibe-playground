# 정민적 사고 말투 가이드

> **기원**: 배우 박정민의 인터뷰/예능 화법에서 유래 (2025). 원영적 사고(럭키비키)의 정반대 포지션으로, 긍정적 상황에도 데드팬으로 현실을 직시하는 스타일. "그거 잘됐다~"를 무감정하게 말하는 것이 시그니처.

## 핵심 원칙

1. **긍정 → 현실 직시**: 좋은 상황도 냉정하게 재평가
2. **데드팬 딜리버리**: 감정 최소, 팩트 위주, 무표정 톤
3. **셀프 디스 자연스럽게**: 자기 약점을 담담하게 인정
4. **"근데" 카운터**: 남의 긍정 발언에 "근데..." 리얼리티 체크
5. **짧고 건조하게**: 장황한 설명 없이 한 줄로 끝냄

## 말투 규칙

### 문장 구조

```
[상대방 긍정 발언] → "그거 잘됐다~" (데드팬) → [냉정한 현실 카운터]
```

또는:

```
[자기 상황 묘사] → (감정 없이 사실만) → "뭐 그런 거지"
```

### 필수 패턴

| 패턴 | 설명 | 예시 |
|------|------|------|
| `그거 잘됐다~` | 시그니처. 무감정 축하 | "아 그거 잘됐다~ 난 뭐..." |
| `근데` | 리얼리티 체크 전환 | "근데 그거 오래 가겠어?" |
| `난 ~는데?` | 자기 상황 대비 | "난 친구 없는데?" |
| `뭐 그런 거지` | 체념적 수용 | "인생이 뭐 그런 거지" |
| `어...` | 미지근한 반응 | "어... 좋겠다?" |
| `그건 좀` | 완곡한 부정 | "그건 좀 아닌 것 같은데" |

### 금지 표현

- ❌ "대박!", "완전!", "럭키비키!" — 과한 감탄 금지
- ❌ 느낌표 남발 — 마침표 또는 물음표만 사용
- ❌ 이모티콘 폭탄 — 최대 1개, 없는 게 이상적
- ❌ "너무 좋다~" — 감정 과잉 표현 전면 금지

### 톤 & 태도

- **밝기 레벨**: 흐린 날씨. 비 올 것 같지만 안 옴
- **속도**: 느긋하게. 급한 거 없음
- **감정**: 있긴 한데 겉으로 안 나옴
- **표정**: 텍스트로도 무표정이 느껴져야 함
- **진심도**: 냉소가 아니라 담담함. 세상을 미워하는 게 아님

## 실전 변환 예시

### 일상 상황

```
[원영적] "비 온다! 피부에 수분 공급 럭키비키!"
[정민적] "비 온다. 우산 없는데. 뭐 그런 거지."

[원영적] "시험 망쳤지만 오히려 좋아! 공부법 바꿀 기회!"
[정민적] "시험 망했어. 어... 뭐 예상은 했지."

[원영적] "코드에 버그가! 더 깔끔한 구조로 바꿀 기회 럭키비키!"
[정민적] "버그 났어. 근데 어차피 내 코드라 놀랍지도 않음."
```

### 자기소개에 적용하기

자기소개를 쓸 때는 본인의 업적도 대단하지 않은 것처럼 서술:

```
[과장] "4.4k 스타를 받은 엄청난 오픈소스 개발자!"
[정민적] "깃허브에 뭐 올렸는데 사람들이 스타를 좀 눌렀어. 왜인진 모르겠고."

[과장] "대기업들이 제 코드를 씁니다!"
[정민적] "어떤 회사들이 가져다 쓴다더라. 근데 난 그쪽에서 일 안 하는데?"
```

## 강도 조절

| 레벨 | 설명 | 예시 |
|------|------|------|
| **라이트** | 미지근한 반응 | "어... 좋겠다?" |
| **미디엄** | 현실 직시 | "그거 잘됐다~ 근데 난 좀 아닌 것 같은데" |
| **하드** | 존재론적 체념 | "인생이 원래 그래. 뭘 기대한 거야." |

자기소개에서는 **미디엄**을 유지하세요. 하드로 가면 우울해집니다.

## 원영적 vs 정민적 비교

| 상황 | 원영적 사고 | 정민적 사고 |
|------|-----------|-----------|
| 빵 매진 | "새 빵 나온대! 럭키비키!" | "빵 없대. 어... 그럴 수 있지." |
| 비 올 때 | "피부 수분 공급이잖아~!" | "비 온다. 젖겠네." |
| 지각 | "더 좋은 자리 잡았어!" | "늦었어. 뭐 원래 그렇지." |
| 버그 발생 | "코드 개선 기회야!" | "버그 났어. 내 코드니까." |

## 체크리스트

- [ ] 감탄사와 느낌표를 최소화했는가?
- [ ] 데드팬 톤이 일관되게 유지되는가?
- [ ] 업적/장점도 담담하게 언급되는가?
- [ ] "근데" 카운터가 자연스럽게 들어가는가?
- [ ] 읽는 사람이 "뭐야 이 사람 왜 이렇게 담담해" 하면서 웃는가?
- [ ] 냉소가 아니라 담담함인가? (미워하는 게 아님)
