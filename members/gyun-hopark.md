# gyun-hopark

## 한 줄 소개
코드로 이것저것 실험해 보는 메이커형 개발자입니다.

## 관심사 / 취미
- 새로운 도구 찍먹하고 손에 맞게 다듬기
- 작은 아이디어를 바로 만들어 보는 프로토타이핑
- 기록 남기기, 정리하기, 흐름 개선하기

## 좋아하는 기술 스택이나 도구
- TypeScript
- React
- GitHub
- CLI 기반 개발 도구

## 하고 싶은 말
완벽하게 시작하기보다 일단 만들어 보고, 계속 고쳐 가는 쪽을 좋아합니다. 같이 재미있는 것 많이 만들어 봐요.
